# Full Stack AI Blog Platform (MERN)

A full-stack blogging platform built with the **MERN stack (MongoDB, Express, React, Node.js)**.  
This project integrates **Artificial Intelligence (AI)** to generate blog content automatically and provides an **admin dashboard** for managing blogs and comments.

The platform allows users to read blogs while admins can create, edit, and manage content through a secure interface.

---

## Features

### Public Features

- View blog posts
- Responsive modern UI
- Blog detail pages
- Comment system
- AI-generated blog content

### Admin Dashboard

- Admin login
- Create new blog posts
- Generate blog content using AI
- Upload blog images
- Edit existing blogs
- Delete blogs
- Manage comments

### Backend Features

- RESTful API
- MongoDB database integration
- Image upload support (ImageKit)
- Secure environment configuration
- Scalable Express server
